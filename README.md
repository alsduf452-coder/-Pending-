# 양산 설비 PENDING 통합 관리

CVD15I / CVD45I 통합 Pending Excel을 읽는 Python·Streamlit 웹앱입니다.
기존 README에 있던 조회 기능과 판정 기준을 실제 화면으로 구현했습니다.

## 처음 실행하기 (Windows)

1. Python 3.12를 설치합니다. 설치 화면의 **Add Python to PATH**를 체크합니다.
2. 프로젝트 ZIP을 다운로드하고 **압축 풀기**를 누릅니다.
3. 압축 푼 폴더에서 주소 표시줄에 `cmd`를 입력하고 Enter를 누릅니다.
4. 열린 명령창에 다음 명령을 한 줄씩 입력합니다.

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

5. 브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 http://localhost:8501 을 입력합니다.
6. 왼쪽 **Pending Excel 업로드 → Browse files**를 클릭하고 원본 Excel을 선택합니다.
7. **실제 Excel** 모드와 **주요 5개 분야**가 선택됐는지 확인합니다.
8. 왼쪽 설비·분야·상태를 선택하거나, 중앙 검색창에 키워드를 입력합니다.
9. 아래 **상세 항목 선택**을 클릭하면 원문과 시트·행 출처를 확인할 수 있습니다.
10. 화면 하단 **조회 결과 CSV / Excel**을 클릭하면 현재 필터 결과가 저장됩니다.

명령창을 닫으면 앱도 종료됩니다. 다시 실행할 때는 마지막 실행 명령만 입력하면 됩니다.
`python`이 없다고 나오면 Python을 설치한 뒤 명령창을 새로 열거나 `py`를 사용하세요.
포트가 사용 중이면 실행 명령 뒤에 `--server.port 8502`를 붙이고 http://localhost:8502 로 접속합니다.

## macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

브라우저에서 http://localhost:8501 로 접속합니다. 클라우드 환경의 localhost는 사용자 PC와 다릅니다.
이 프로젝트는 로컬 실행용이며 공개 사이트로 배포하지 않았습니다.

## 데이터 사용 방법

- 기본은 원본 업로드입니다. 업로드 파일을 디스크에 쓰거나 원본을 수정하지 않습니다.
- 매번 업로드하기 싫다면 원본의 **복사본**을 `data/source.xlsx`로 두세요. 업로드한 파일이 우선입니다.
- 원본 파일이 없을 때 실제 데이터를 만들어 표시하지 않습니다. **샘플 데이터** 모드를 직접 선택하면 `data/sample.csv`의 가상 예시 12건을 표시합니다.
- 배포용 ZIP에는 실제 Excel을 포함하지 않습니다. 사용자가 보유한 원본을 업로드하세요.
- 같은 시트명·열 구조의 `.xlsx`를 지원합니다. 임의의 Excel 열 매핑 기능은 없습니다.

## 집계 규칙

완료는 원문 상태 O/○/완료만 인정합니다. 고객사요청 상단 표는 H/I열 두 값이 모두 완료여야 완료입니다.
39행 이후 별도 표는 J열 완료 여/부 및 H열 목표일을 사용합니다. 완료로 명시되지 않은 상태와 공란은 모두 **미완료**입니다.
카드·상세 표·차트·입력 폼·다운로드에서 완료/미완료 두 상태만 사용합니다. 설비가 없는 행은 **미기재**로 표시합니다.
45호기 적용 여부만으로 항목의 설비를 바꾸거나 새 항목을 생성하지 않습니다.

기본 집계는 HW(설계)·공정·SW·전장·기타만 사용합니다. 보조 시트(고객사요청·software불합리·설비알람)는 별도 범위로 조회합니다.
중복 제거·연도 추정·날짜 기반 지연 판정은 하지 않습니다. Rev 관리·Robot Teaching 메모·이미지·도형은 구조화하지 않습니다.
상세 행 상태 기준이므로 Excel 요약 수식 캐시와 다를 수 있습니다. 설비알람에는 명시적 완료 상태가 없어 미완료로 분류합니다.

첨부 원본 검증 결과: 주요 분야 174건, 완료 160건, 미완료 14건, 완료율 92.0%.
보조 시트는 고객사요청 116건, software불합리 81건, 설비알람 17건입니다. 중복 가능성이 있으므로 합산 시 유의하세요.

## 기본 Excel 지정 및 새 Pending 등록

1. 왼쪽에서 **실제 Excel**을 선택하고 기존 원본을 업로드합니다.
2. **이 Excel을 기본값으로 저장**을 누릅니다. `data/default.xlsx`에 별도 복사본을 저장하며, 원본 파일은 수정하지 않습니다.
3. 다음 실행부터 업로드 없이 이 기본 Excel을 불러옵니다. 다른 파일을 기본값으로 지정하면 기본 복사본만 교체합니다.
4. **＋ 새 Pending 항목 등록**을 펼치고 설비·분야·내용 및 필요한 정보를 입력합니다.
5. **Pending 저장**을 누르면 목록·집계·그래프·다운로드에 반영됩니다. 등록 항목의 출처는 **화면 등록**입니다.

새 항목은 `data/pending.sqlite3`에 저장되어 개인 PC에서 재실행해도 유지됩니다.
파일 내용의 SHA-256으로 Excel을 구분하므로, 다른 Excel에는 이전 추가 항목이 섞이지 않습니다.
원본 Excel을 외부에서 수정한 경우에는 다른 데이터로 인식합니다. 기존 파일로 돌아가면 기존 추가 항목을 다시 불러옵니다.
샘플 모드에서는 저장 기능을 제공하지 않습니다. 추가 항목의 수정·삭제는 이번 기능에 포함하지 않습니다.

업데이트할 때 기존 프로젝트 폴더에 코드를 덮어쓰되 **data 폴더의 default.xlsx와 pending.sqlite3를 보존**하세요.
백업하려면 앱을 종료하고 두 파일을 별도 안전한 폴더로 복사하세요. 조회 결과 Excel은 내보내기용으로, 원본 형식 재업로드용은 아닙니다.
Streamlit Community Cloud의 로컬 디스크는 재배포·인스턴스 교체 시 보존이 보장되지 않습니다. 장기 보관은 개인 PC 로컬 실행을 사용하세요.
원본 Excel과 로컬 데이터베이스는 GitHub에 업로드하지 않습니다.

## 항목 수정·완료 처리 및 변경 이력

- 목록 아래 **상세 항목 선택**에서 대상을 고르고 **항목 수정 / 완료 처리**를 펼칩니다.
- 변경자를 입력하고 내용·담당자·목표일·진행 사항·조치내용·상태 등을 수정한 뒤 **수정 내용 저장**을 누릅니다.
- **완료 처리 후 저장**은 상태를 완료로 바꾸고, 완료일이 비어 있으면 한국 시간 기준 오늘 날짜를 기록합니다. 기존 날짜는 보존합니다.
- **이 항목의 변경 이력**과 화면 하단 **전체 변경 이력**에서 변경자, 한국 시간, 변경 필드, 이전 값과 이후 값을 확인합니다. 이력 CSV 다운로드도 제공합니다.
- 변경자 이름은 직접 입력하는 값이며 로그인 인증 정보가 아닙니다.
- 원본 Excel과 원문 상태는 보존합니다. 현재 상태·수정값은 별도 DB에 저장되며 집계·검색·내보내기에 반영됩니다.
- 동시 수정이 감지되면 덮어쓰지 않고 새로고침 안내를 표시합니다.
- 기존 pending.sqlite3에 테이블을 추가하므로 등록해둔 항목을 삭제하지 않습니다.

### 업로드 없이 기본 Excel 열기

`data/default.xlsx`가 있으면 앱 시작 시 자동으로 열고, 없으면 `data/source.xlsx`를 사용합니다.
업데이트할 때 기존 `data/default.xlsx`와 `data/pending.sqlite3`를 보존하세요.
실제 Excel을 공개 GitHub에 포함하지 않으므로 새로 다운로드한 폴더에는 실제 기본 파일이 없습니다.
이미 저장한 기본 파일을 새 폴더의 data 폴더로 복사하면 업로드할 필요가 없습니다.
최초 설정 시에도 원본의 **복사본**을 `data/default.xlsx`로 저장하면 앱 내 업로드 없이 실행할 수 있습니다.
추가 항목과 수정·이력은 Excel 파일 내용에 연결됩니다. 다른 내용의 Excel로 교체하면 기존 항목과 이력이 분리됩니다.

## Excel Rev 관리 화면

앱 이름을 **양산 설비 PENDING 통합 관리**로 변경했습니다.
상단 **화면 선택 → REV 관리**에서 원본 첫 시트의 제목·라인·공정, 분야별 요약 집계와 Rev 변경 이력을 확인합니다.
Rev 번호를 선택하면 전체 변경내용·작성자·날짜·비고·원본 행을 표시하며 CSV 다운로드를 지원합니다.
Excel의 저장된 요약 수식 캐시를 읽는 화면으로, 현재 필터나 앱에서 등록·수정한 항목은 반영하지 않습니다.
Excel Rev 이력과 앱의 항목 변경 이력은 별도 관리합니다. 원본이 없는 샘플 모드는 실제 Rev 정보를 표시하지 않습니다.

## REV-02 화면 업데이트 방법

제목·사이드바·브라우저 탭에 **양산 설비 PENDING 통합 관리**가 표시됩니다.
제목 바로 아래 **화면 버전 REV-02**, **Pending 현황 / REV 관리** 메뉴를 확인하세요.
**REV 관리**는 접힌 영역이 아닌 독립 화면이며, 분야별 가로 요약표와 줄바꿈을 유지하는 변경 이력 표·검색·상세를 제공합니다.
REV 이력이 없는 파일이나 샘플 모드에서도 이유를 표시합니다.

1. 기존 앱 명령창에서 Ctrl+C로 종료합니다.
2. 최신 ZIP을 압축 해제하고 `app.py`, `pending_data.py`, `pending_store.py`, `start_app.cmd`를 **기존에 사용하던 폴더**에 복사해 덮어씁니다.
3. `data` 폴더와 `.venv` / `.venv312` 폴더는 교체하지 않습니다.
4. 해당 폴더에서 `start_app.cmd`를 실행하거나 기존 Python 환경으로 `-m streamlit run app.py`를 실행합니다.
5. 브라우저를 새로고침하고 화면 버전 REV-02와 새 제목을 확인한 뒤 **REV 관리**를 누릅니다.

다른 폴더의 예전 코드가 실행되면 변경된 화면이 나오지 않습니다. 왼쪽 **실행 정보 확인**에서 실제 실행 파일 경로를 확인할 수 있습니다.
`start_app.cmd`는 자신의 위치에서 실행하며 `.venv312`, `.venv` 순으로 환경을 선택합니다. 라이브러리가 없는 환경이면 requirements.txt로 해당 환경에 설치해야 합니다.
회사 정책상 CMD 스크립트를 실행할 수 없다면 허용된 PowerShell에서 다음 명령을 입력하세요.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`.venv312`를 사용하는 경우 해당 경로로 바꿔 실행하세요.

## REV-03: REV 등록 및 수정

**REV 관리 → 새 REV 등록**에서 번호, 구분, 주요 변경내용, 변경일자, 작성자, 비고, 등록자를 입력하고 **새 REV 저장**을 누릅니다.
다음 번호를 자동 제안하며 번호는 직접 지정할 수 있습니다. `001`과 `1`은 같은 번호로 판단해 중복 등록을 막습니다.
번호·주요 변경내용·변경일자·작성자·등록자는 필수입니다.

기존 이력에서 **REV 상세 선택 → 선택한 REV 수정**을 펼치고 변경자와 수정 내용을 입력한 뒤 **REV 수정 저장**을 누릅니다.
Excel에서 읽은 REV와 앱에서 추가한 REV를 모두 수정할 수 있습니다. 출처 열에서 원본·앱 수정·화면 등록 여부를 확인합니다.
**선택한 REV의 등록·변경 기록 / REV 전체 등록·변경 기록**에 변경 전후 값과 한국 시간, 등록·변경자를 기록하고 CSV로 내보낼 수 있습니다.
원본 날짜 표기(여러 날짜가 한 셀에 있는 경우 포함)는 그대로 유지하고 수정할 수 있습니다. 새 날짜는 YYYY-MM-DD로 입력하세요.

Pending 항목 수정 내용이 REV로 자동 변환되지는 않습니다. 필요한 변경점을 REV로 직접 기록하세요.

- 작업 이력은 10건 단위 카드로 표시합니다. 날짜·작업 순서·챔버·작업 유형·부품·결과·전후 S/N·사유·내용·작업자를 보고 **상세 / 수정 / 삭제 / 부품 이동 추적**을 바로 실행할 수 있습니다. **표로 보기**에서 기존 목록과 Excel/CSV를 사용할 수 있습니다.

- 삭제는 담당자·사유를 입력하고 **삭제 보관 확인**을 눌러야 반영됩니다. 기본 목록·월별 집계·장착 계산에서 제외하며 파일/첨부/측정 기록은 삭제하지 않습니다. **삭제 보관함**에서 담당자·사유를 입력해 복원합니다. 삭제·복원 전후 값과 담당자는 변경 이력 및 백업에 남습니다. 초기 장착 기준 자체는 보존합니다.

## HW-03: 측정 수치·위치도 2분할 및 챔버별 측정 이력

- **Spacing**: 왼쪽 50%에 실제 배치 ①⑥② / ⑨⑤⑦ / ④⑧③의 9개 수치 카드, 오른쪽 50%에 같은 배치와 숫자가 있는 측정 위치도를 표시합니다. 넓은 다색 히트맵은 제거하고 중립색 도면·Center 강조와 차이 글자색만 사용합니다.
- Spacing 기준 885 mils는 AI Studio 원본의 시각 비교 기준으로, 설비 규격이나 자동 양불 판정 기준은 아닙니다. 기준 대비 차이와 최소/최대/편차/측정 개수를 표시합니다.
- **Flatness**: 왼쪽 50%에 5×7 숫자 편집표, 오른쪽 50%에 각 값과 R/C 위치가 적힌 부품 위치도를 표시합니다. Col 1이 Gate Valve 측, Col 7이 Window 측입니다.
- 범례는 **낮은 값 파랑(#2563eb) → 높은 값 빨강(#ef4444)**으로 통일했습니다. SVG 도면에는 음영을 추가하고 3D에는 같은 색상 방향과 조명을 적용합니다. 모든 실측값이 같으면 중립색으로 표시합니다. 음영은 입체 표현이며 측정값을 바꾸지 않습니다.
- 미측정은 회색/—, 실제 0은 숫자 0으로 표시합니다. 빈값을 임의 보간하거나 0으로 대체하지 않습니다.
- 왼쪽 표를 편집하면 오른쪽 도면이 즉시 미리보기됩니다. **수치 변경자 → 편집한 측정값 저장**을 눌러야 DB 및 변경 이력에 기록합니다. **입력 되돌리기**로 저장 전 입력을 취소할 수 있습니다. 날짜·SN·비고는 별도 측정 정보 수정 영역에서 바꿉니다.
- 기존 **측정 기록 선택** 드롭다운을 없앴습니다. 화면 아래 **챔버·측정 종류별 측정 이력**에 날짜·시점·부품 SN·측정기·Max−Min·비고를 바로 표시하고 각 행의 **보기/수정**으로 기록을 엽니다. 위쪽의 기존 챔버 선택과 검색 조건을 따르며 새 이력 선택창은 추가하지 않습니다. 전체 챔버일 때도 서로 다른 챔버와 Diffuser/Susceptor는 별도 표로 분리합니다.
- 기존 영문 필드 단위 원시 변경 로그는 **선택 측정의 필드별 수정 기록 · 상세 로그**로 분리했습니다. 기존 감사 기록을 삭제하지 않습니다.

## HW-04: 측정 설명 정리·종류 카드·전후 비교

- 측정 설명은 S/N, 측정 구분(작업 전/후), 비고, 원문 출처를 각각 다른 줄에 표시합니다.
- Spacing/Flatness 제목에서 왼쪽/오른쪽 50% 문구를 제거했습니다. 두 숫자표와 위치도는 같은 SVG 좌표·크기로 표시해 수치 위치·높이를 맞췄습니다. 편집 입력창을 공통 영역 아래로 옮겨 접힘 여부가 양쪽 시각 자료 정렬에 영향을 주지 않게 했습니다.
- **수치 직접 편집**을 펼쳐 수정하면 위쪽 숫자표와 위치도가 즉시 미리보기됩니다. 변경자를 입력하고 저장해야 DB가 바뀝니다. 원본 수치·빈값·0은 기존 규칙대로 보존합니다.
- Flatness 상단에 **Diffuser Flatness / Susceptor Flatness** 카드를 분리했습니다. 현재 설비·챔버 범위의 건수를 표시하며 표·위치도·이력·내보내기는 선택한 종류로 제한됩니다. 새 측정 등록도 선택한 카드의 종류를 기본값으로 합니다.
- 첨부 백업의 실제 종류별 건수: CVD15I Diffuser 17건/Susceptor 5건, CVD45I Diffuser 12건/Susceptor 12건입니다. 이미 백업을 가져왔다면 추가 업로드 없이 표시합니다. 저장소에 없는 기록을 자동 생성하지 않습니다.
- **측정 보기 방식 → 작업 전후 비교**를 선택하면 같은 설비·챔버·종류의 A/B 기록을 직접 선택합니다. 기본값은 선택 기록과 그 직전 기록(첫 기록이면 다음 기록)이며, 같은 날짜에 여러 기록이 있으면 원본 순서와 ID를 함께 확인할 수 있습니다. 기록이 한 건뿐이면 비교 데이터를 만들지 않고 안내합니다.
- A와 B는 각각 수치·위치도·최소/최대/편차를 보여주며, 위치별 **B−A 변화량**과 CSV/Excel 내보내기를 제공합니다. 한쪽이 미측정이면 변화량도 빈값으로 유지합니다. Spacing은 ⑤−①·⑤−②·⑤−③·⑤−④·②−④·①−③의 전후 값과 변화량도 제공합니다.
- Flatness 비교에서는 A/B 전체의 실측 최소·최대를 공통 색상 범위로 사용합니다. 같은 숫자는 같은 색이며, 3D 비교도 같은 색상 및 Z축 범위를 사용합니다. 낮은 값 파랑/높은 값 빨강과 음영을 유지합니다.
- 비교는 저장된 기록을 읽기만 합니다. 다른 설비·챔버 또는 Diffuser와 Susceptor 사이의 비교는 허용하지 않습니다. 저장하지 않은 편집값은 비교에 포함하지 않습니다.
