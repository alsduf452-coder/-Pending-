# Pending Intelligence

첨부된 CVD15I/45I 통합 Pending 엑셀을 조회하는 로컬 웹 도구입니다.

## 실행
```sh
cd /workspace/-Pending-
python -m pip install -r requirements.txt
python app.py --port 8000
```

대시보드, 분야·설비·상태 필터, 통합 검색, 원문 상세와 시트/행 출처, CSV 내보내기, 질문 형태의 키워드 검색을 제공합니다. 원본은 `data/source.xlsx`에 보관합니다. 동일한 열 구조의 파일로 교체하고 서버를 재시작하면 갱신됩니다.

질문 검색은 로컬 규칙 기반이며 생성형 AI에 연결되지 않았습니다. 데이터는 외부 AI로 전송되지 않습니다. 원인 진단이나 설비 제어 기능은 없습니다.

완료는 원문 상태 O/○/완료로 판정합니다. 고객사 요청 상단 표는 H/I열 두 상태가 모두 완료인 경우 완료로 판정합니다. 39행부터는 별도 표의 완료 여/부 및 목표일을 사용합니다. 미기재는 확인 필요입니다. 요약 집계는 주요 5개 분야만 사용하고 보조 시트는 목록에 별도로 포함합니다. 중복 제거·누락된 연도 추정·날짜 기반 지연 판정은 수행하지 않습니다. 이미지/도형과 Rev 관리, Robot Teaching 메모는 구조화하지 않습니다. 상세 행 상태를 기준으로 하므로 엑셀 요약 수식의 캐시 집계와 차이가 있을 수 있습니다.

내부 검토용 프로토타입이며 인증과 다중 사용자 편집은 구현되지 않았습니다. 원본 및 담당자 정보가 포함되므로 공개 배포 전 접근 제어가 필요합니다.
