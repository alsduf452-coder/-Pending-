# Pending Intelligence

CVD15I / CVD45I 통합 Pending Excel을 읽는 Python·Streamlit 웹앱입니다.
기존 README에 있던 조회 기능과 판정 기준을 실제 화면으로 구현했습니다.

## 처음 실행하기 (Windows)

1. Python 3.12를 설치합니다. 설치 화면의 **Add Python to PATH**를 체크합니다.
2. 프로젝트 ZIP을 다운로드하고 **압축 풀기**를 누릅니다.
3. 압축 푼 폴더에서 주소 표시줄에 `cmd`를 입력하고 Enter를 누릅니다.
4. 열린 명령창에 다음 명령을 한 줄씩 입력합니다.

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

5. 브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 http://localhost:8501 을 입력합니다.
6. 왼쪽 **Pending Excel 업로드 → Browse files**를 클릭하고 원본 Excel을 선택합니다.
7. **실제 Excel** 모드와 **주요 5개 분야**가 선택됐는지 확인합니다.
8. 왼쪽 설비·분야·상태를 선택하거나, 중앙 검색창에 키워드를 입력합니다.
9. 아래 **상세 항목 선택**을 클릭하면 원문과 시트·행 출처를 확인할 수 있습니다.
10. 화면 하단 **조회 결과 CSV / Excel**을 클릭하면 현재 필터 결과가 저장됩니다.

명령창을 닫으면 앱도 종료됩니다. 다시 실행할 때는 마지막 실행 명령만 입력하면 됩니다.
`python`이 없다고 나오면 Python을 설치한 뒤 명령창을 새로 열거나 `py`를 사용하세요.
포트가 사용 중이면 실행 명령 뒤에 `--server.port 8502`를 붙이고 http://localhost:8502 로 접속합니다.

## macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

브라우저에서 http://localhost:8501 로 접속합니다. 클라우드 환경의 localhost는 사용자 PC와 다릅니다.
이 프로젝트는 로컬 실행용이며 공개 사이트로 배포하지 않았습니다.

## 데이터 사용 방법

- 기본은 원본 업로드입니다. 업로드 파일을 디스크에 쓰거나 원본을 수정하지 않습니다.
- 매번 업로드하기 싫다면 원본의 **복사본**을 `data/source.xlsx`로 두세요. 업로드한 파일이 우선입니다.
- 원본 파일이 없을 때 실제 데이터를 만들어 표시하지 않습니다. **샘플 데이터** 모드를 직접 선택하면 `data/sample.csv`의 가상 예시 12건을 표시합니다.
- 배포용 ZIP에는 실제 Excel을 포함하지 않습니다. 사용자가 보유한 원본을 업로드하세요.
- 같은 시트명·열 구조의 `.xlsx`를 지원합니다. 임의의 Excel 열 매핑 기능은 없습니다.

## 구현된 기능

- 상단 전체 건수·완료·미완료·완료율 카드
- 사이드바 설비·분야·상태·조회 범위 필터
- 분야별/설비별 누적 막대그래프 및 완료율 표
- 전체 원문 키워드 검색: 공백으로 나눈 단어를 모두 포함하는 항목 조회, 대소문자 무시
- 간단한 질문 검색: `Robot 관련 미완료 항목 알려줘`처럼 설비/상태/키워드 추출. 자연어 해석은 제한적이며 화면에 해석 조건을 표시합니다.
- Pending 목록, 항목별 상세, 원문 상태 및 시트·Excel 행 번호
- 현재 결과 CSV(한글 Excel용 UTF-8 BOM), Excel(목록·분야 집계·설비 집계)
- 검색 결과 없음·잘못된 파일·원본 없음 안내

## 집계 규칙

완료는 원문 상태 O/○/완료만 인정합니다. 고객사요청 상단 표는 H/I열 두 값이 모두 완료여야 완료입니다.
39행 이후 별도 표는 J열 완료 여/부 및 H열 목표일을 사용합니다. 공란 또는 확인필요는 **확인 필요**입니다.
미완료 카드에는 확인 필요를 포함하고, 상세 표·차트에서는 구분합니다. 설비가 없는 행은 **미기재**로 표시합니다.
45호기 적용 여부만으로 항목의 설비를 바꾸거나 새 항목을 생성하지 않습니다.

기본 집계는 HW(설계)·공정·SW·전장·기타만 사용합니다. 보조 시트(고객사요청·software불합리·설비알람)는 별도 범위로 조회합니다.
중복 제거·연도 추정·날짜 기반 지연 판정은 하지 않습니다. Rev 관리·Robot Teaching 메모·이미지·도형은 구조화하지 않습니다.
상세 행 상태 기준이므로 Excel 요약 수식 캐시와 다를 수 있습니다. 설비알람에는 명시적 완료 상태가 없어 확인 필요로 분류합니다.

첨부 원본 검증 결과: 주요 분야 174건, 완료 160건, 미완료 14건, 완료율 92.0%.
보조 시트는 고객사요청 116건, software불합리 81건, 설비알람 17건입니다. 중복 가능성이 있으므로 합산 시 유의하세요.

## 파일 구성과 GitHub 반영

- `app.py`: 한국어 화면
- `pending_data.py`: 읽기 전용 Excel 해석·검색·집계·다운로드
- `requirements.txt`: 실행 라이브러리
- `.streamlit/config.toml`: 색상·업로드 설정
- `data/sample.csv`: 명시적 가상 샘플
- `tests/`: 파싱·검색·내보내기·화면 테스트
- `.gitignore`: 원본 Excel·가상환경·캐시 제외

기존 저장소에 위 파일을 반영하세요. `work/`와 원본 Excel은 GitHub에 올리지 않습니다.

```sh
git add app.py pending_data.py requirements.txt README.md .gitignore .streamlit/config.toml data/sample.csv data/.gitkeep tests
git diff --cached
git commit -m "Build Streamlit Pending Intelligence application"
```

GitHub 반영 전 변경사항을 검토하고 사용 중인 브랜치로 push하세요. 이번 작업에서 원격 push는 수행하지 않았습니다.

## 검증

Python 3.12에서 라이브러리 설치, Streamlit AppTest 화면 조작, Excel 읽기·상태 판정·검색·다운로드·원본 해시 보존 테스트를 실행했습니다.

```sh
python -m pip install pytest
python -m pytest -q
```

실제 원본 통합 테스트는 `data/source.xlsx`가 없으면 건너뜁니다.
내부 검토용 조회 도구이며 인증·다중 사용자 편집은 없습니다. 외부 AI 서비스로 데이터를 전송하지 않습니다.

## 기본 Excel 지정 및 새 Pending 등록

1. 왼쪽에서 **실제 Excel**을 선택하고 기존 원본을 업로드합니다.
2. **이 Excel을 기본값으로 저장**을 누릅니다. `data/default.xlsx`에 별도 복사본을 저장하며, 원본 파일은 수정하지 않습니다.
3. 다음 실행부터 업로드 없이 이 기본 Excel을 불러옵니다. 다른 파일을 기본값으로 지정하면 기본 복사본만 교체합니다.
4. **＋ 새 Pending 항목 등록**을 펼치고 설비·분야·내용 및 필요한 정보를 입력합니다.
5. **Pending 저장**을 누르면 목록·집계·그래프·다운로드에 반영됩니다. 등록 항목의 출처는 **화면 등록**입니다.

새 항목은 `data/pending.sqlite3`에 저장되어 개인 PC에서 재실행해도 유지됩니다.
파일 내용의 SHA-256으로 Excel을 구분하므로, 다른 Excel에는 이전 추가 항목이 섞이지 않습니다.
원본 Excel을 외부에서 수정한 경우에는 다른 데이터로 인식합니다. 기존 파일로 돌아가면 기존 추가 항목을 다시 불러옵니다.
샘플 모드에서는 저장 기능을 제공하지 않습니다. 추가 항목의 수정·삭제는 이번 기능에 포함하지 않습니다.

업데이트할 때 기존 프로젝트 폴더에 코드를 덮어쓰되 **data 폴더의 default.xlsx와 pending.sqlite3를 보존**하세요.
백업하려면 앱을 종료하고 두 파일을 별도 안전한 폴더로 복사하세요. 조회 결과 Excel은 내보내기용으로, 원본 형식 재업로드용은 아닙니다.
Streamlit Community Cloud의 로컬 디스크는 재배포·인스턴스 교체 시 보존이 보장되지 않습니다. 장기 보관은 개인 PC 로컬 실행을 사용하세요.
원본 Excel과 로컬 데이터베이스는 GitHub에 업로드하지 않습니다.

## 항목 수정·완료 처리 및 변경 이력

- 목록 아래 **상세 항목 선택**에서 대상을 고르고 **항목 수정 / 완료 처리**를 펼칩니다.
- 변경자를 입력하고 내용·담당자·목표일·진행 사항·조치내용·상태 등을 수정한 뒤 **수정 내용 저장**을 누릅니다.
- **완료 처리 후 저장**은 상태를 완료로 바꾸고, 완료일이 비어 있으면 한국 시간 기준 오늘 날짜를 기록합니다. 기존 날짜는 보존합니다.
- **이 항목의 변경 이력**과 화면 하단 **전체 변경 이력**에서 변경자, 한국 시간, 변경 필드, 이전 값과 이후 값을 확인합니다. 이력 CSV 다운로드도 제공합니다.
- 변경자 이름은 직접 입력하는 값이며 로그인 인증 정보가 아닙니다.
- 원본 Excel과 원문 상태는 보존합니다. 현재 상태·수정값은 별도 DB에 저장되며 집계·검색·내보내기에 반영됩니다.
- 동시 수정이 감지되면 덮어쓰지 않고 새로고침 안내를 표시합니다.
- 기존 pending.sqlite3에 테이블을 추가하므로 등록해둔 항목을 삭제하지 않습니다.

### 업로드 없이 기본 Excel 열기

`data/default.xlsx`가 있으면 앱 시작 시 자동으로 열고, 없으면 `data/source.xlsx`를 사용합니다.
업데이트할 때 기존 `data/default.xlsx`와 `data/pending.sqlite3`를 보존하세요.
실제 Excel을 공개 GitHub에 포함하지 않으므로 새로 다운로드한 폴더에는 실제 기본 파일이 없습니다.
이미 저장한 기본 파일을 새 폴더의 data 폴더로 복사하면 업로드할 필요가 없습니다.
최초 설정 시에도 원본의 **복사본**을 `data/default.xlsx`로 저장하면 앱 내 업로드 없이 실행할 수 있습니다.
추가 항목과 수정·이력은 Excel 파일 내용에 연결됩니다. 다른 내용의 Excel로 교체하면 기존 항목과 이력이 분리됩니다.
