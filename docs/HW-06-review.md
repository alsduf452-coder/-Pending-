# HW-06 비교 검토 (2026-10-22)

검토 대상: HW-05 Streamlit 코드와 사용자가 첨부한 AI Studio 소스 ZIP의 React 컴포넌트. 실행 환경이 다른 두 앱의 코드상 기능을 비교했으며 Firebase 서비스의 실제 운영 상태를 검증한 것은 아닙니다. HW-06에는 REV 상세 격자만 적용했습니다. 아래 사항은 제안이며 삭제·추가하지 않았습니다.

## 현재 유지할 기능
Pending 기본 Excel·항목 수정·완료 처리·REV 등록/수정, H/W 작업 카드 수정/삭제 보관/복원·부품 S/N 추적·첨부, 365일 경과 색상(원본 예외 부품 포함), 월별 연도/챔버/8종 부품 필터, Spacing 및 Diffuser/Susceptor Flatness 구분·전후 비교·3D, 로컬 DB 변경 이력 및 통합 백업은 유지할 가치가 있습니다. 기존 기능을 다시 만드는 대신 사용 흐름을 정리하는 것을 권장합니다.

## 제외하거나 접어둘 부분
- Firebase 진단·클라우드 동기화 상태·환경 설정 도구: AI Studio Header/FirebaseDiagnosticModal/EnvironmentModal에 있습니다. 현재 로컬 SQLite 운영에는 이전할 필요가 없습니다. 중앙 서버 운영으로 전환하면 인증·저장 방식을 별도 설계해야 합니다.
- 중복된 작업 상세 선택과 수정 폼: 현재 hw_ui.render_hw에서 작업 카드 다음에 상세 선택·수정 UI가 다시 나옵니다. 카드에서 상세를 펼치도록 통합하고 Excel/CSV 표는 유지하는 것을 권장합니다.
- 필드별 원시 변경 로그와 3D: 삭제보다 현재처럼 접힌 보조 기능으로 유지합니다. 일반 사용자는 날짜·변경자·변경 항목 요약을 먼저 볼 수 있으면 좋습니다.
- 초기 셋업에 고정된 표 데이터: AI Studio CheckSheetPhotoModal의 initialSetupRows는 코드에 값이 고정되어 있습니다. 그대로 복제하지 않고 저장된 설비/챔버 초기 장착 데이터로 표를 생성해야 합니다. 원본 파일은 보존합니다.

## 추가 권장
1. H/W Excel 일괄 등록: AI Studio ExcelImportModal은 작업/Spacing/Diffuser/Susceptor를 미리 보고 가져옵니다. 현재 H/W 가져오기는 JSON 중심입니다(Pending Excel 업로드와 별개). 양식 검증·설비/날짜/SN 중복 검토·오류 목록을 포함해 추가하면 반복 입력을 줄입니다.
2. 초기 셋업 원본 조회: AI Studio CheckSheetPhotoModal의 원본/표 탭·확대 기능에 대응합니다. 현재 작업 첨부 조회는 있지만 전용 초기 셋업 화면은 없습니다. 설비/챔버별 실제 원본 파일과 초기 장착 표를 연결하는 것을 권장합니다.
3. 챔버별 부품 가로 비교: 현재 챔버별 현황 표를 부품 행 × 챔버 열로 한눈에 비교하는 보조 화면을 권장합니다. AI Studio EquipmentDetailView의 부품 비교 구성을 참고할 수 있습니다.
4. 여러 사람이 함께 운영할 경우 조회/수정 권한: AI Studio에는 사용자 역할 UI가 있으나 현재 변경자 이름은 직접 입력값입니다. 회사가 허용한 중앙 운영 방식이 정해진 후 인증과 권한을 함께 구현해야 합니다.

## 수정 권장
- 측정 삭제: AI Studio 측정 화면에는 삭제 콜백이 있으나 현재 측정 이력에는 보기/수정만 있습니다. 작업 이력처럼 사유와 변경자를 남기는 삭제 보관·복원 방식이 적합합니다.
- 장착 S/N 정정: AI Studio EditPartSnModal의 직접 정정 흐름을 검토할 가치가 있습니다. 현재 설비 정보 수정은 이름/고객사 위주입니다. 실제 교체 작업과 오기 정정을 구분하고 초기값/측정값을 함께 무단 변경하지 않는 방식이 필요합니다.
- 측정 보고서: 현재 CSV/XLSX 내보내기에 더해 선택한 측정의 위치도·숫자표·A/B 차이를 묶은 인쇄/PDF 보고서를 추가하면 공유하기 좋습니다. 이는 확장 제안입니다.
- 표 표현 통일: 이번 REV 상세처럼 항목명 배경·외곽선·줄바꿈·여백을 작업 상세에도 적용하면 화면 일관성이 높아집니다.

권장 순서: 작업 카드/상세 중복 정리 → 초기 셋업 원본 조회 → H/W Excel 일괄 등록 → 측정 보관/복원 및 S/N 정정 → 챔버 비교·보고서. 공동 운영 인증은 배포 환경이 정해질 때 별도 추진합니다.
